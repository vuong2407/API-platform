# Optimization Checklist

When analyzing code check for:

1. N+1 query problems
2. unnecessary findAll() calls
3. missing pagination
4. inefficient joins
5. large result sets
6. incorrect fetch strategies
7. missing database indexes
8. unnecessary entity loading
